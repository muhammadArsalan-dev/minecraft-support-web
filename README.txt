MINECRAFT-INSPIRED SUPPORTIVE FLOWER WEBSITE

1. Install Flask:
   pip install flask

2. Optional music:
   Put her favourite MP3 at:
   static/music/favourite.mp3

3. Run:
   python app.py

4. Open:
   http://127.0.0.1:5000

The website is Minecraft-inspired using CSS pixel art, blocks, HUD,
grass/dirt terrain, a small house, pixel buttons and flowers.
No Minecraft asset files are required.

The message is intentionally supportive rather than romantic.
Edit templates/index.html if you want to personalize it further.
